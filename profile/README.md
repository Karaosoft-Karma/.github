# Karaosoft Karma — request list on a night karaoke player

Karaosoft Karma keeps one named board on the desk: the live karaoke player, the request in front of you, and a short note the next host can read. Extra nights wait for their own title.

| Focus | Keep only live requests on the Karaosoft Karma board | A short request list |
| Check | Read Karaosoft Karma venue player before the next singer | A confirmed night set |

## How Karaosoft Karma Sits

Karaosoft Karma does not replace the paper slips, the USB stick of tracks, or the generic player you already keep. It sits beside them as a named night desk for one job: which karaoke player is live, which request list still matches the venue player, and what the next host should read.

A first visit should be one short request, then the same Karaosoft Karma night desk the next show. That is enough to see if the venue player list holds.

## Traffic Light

| Signal | On the Karaosoft Karma board | What you do |
|--------|----------------------|-------------|

| Amber | Two nights mixed on one request list | Split the list before the next singer |
| Red | No title, no note, paper passed around the room | Stop and name the night desk first |

## Open Order

1. Open the last Karaosoft Karma night desk, not a new empty karaoke player.
2. Read the request list and the last handoff.
3. Finish one visible venue player pass inside Karaosoft Karma.
4. Write what changed, then close with fewer paper slips than you found.

## After a Week

A week in Karaosoft Karma is not a larger pile of paper passed around the room. It is the same title, a shorter live request list, and a note that still makes sense before the next night you host. Take finished requests off the live set so the next visit starts on the karaoke player that is still open.

## Sign-off

- [ ] The Karaosoft Karma workspace name is short enough to scan
- [ ] Only live requests sit on the player
- [ ] A second host can read the night handoff

## Field Note

Karaosoft Karma is easier to trust when the night desk stays smaller than the paper pile it came from. Name the player, keep the live requests, finish one visible singer, and write what changed.
